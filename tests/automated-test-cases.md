## 测试用例集

### TC-AUTO-001 管理员登录与菜单权限验证 | P0
**前置条件：** 前后端服务已启动，测试数据已加载
**步骤：**
1. 访问 `${base_url}`
2. 在用户名输入框输入 `admin`，密码输入框输入 `Admin@123`
3. 点击登录按钮
4. 等待页面加载完成，检查侧边栏导航菜单
**预期结果：**
- [ ] 登录成功，跳转到运营总览页面
- [ ] 右上角显示用户名"系统管理员"
- [ ] 侧边栏显示7个菜单：运营总览、需求收集、发货审批、执行情况、库存核对、提醒中心、配置管理
- [ ] 右上角不显示区域切换器
- [ ] 顶部显示数据范围提示"全局数据范围"
**选择器参考：**
- 用户名输入框：`input[placeholder*="工号"]` 或 `input[name="employeeNo"]`
- 密码输入框：`input[type="password"]`
- 登录按钮：`button[type="submit"]` 或 `button:contains("登录")`
- 导航菜单：`.sidebar nav a` 或 `[role="navigation"] a`

## 自动化测试执行说明
1. 执行顺序建议：从登录权限类用例开始，再到配置管理、业务流程、数据展示类用例
2. 会修改数据的用例（创建计划、提交需求、导入数据等）建议最后执行，或执行后重置测试数据
3. 重置测试数据命令：`npm run data:load:huawei`
4. 所有权限隔离类用例必须验证后端接口返回403，不能仅验证前端按钮隐藏
5. 每个用例执行失败时自动截图，记录错误信息和网络请求日志
