# MSS样机备货管理平台手工验收用例

## 1. 使用说明

本用例用于在本地或局域网环境验证运营总览、需求收集、发货审批、执行情况、库存核对和基础配置。建议按文档顺序执行；标注“会改变数据”的用例放在最后，或在执行后重新加载测试基线。

### 1.1 准备测试数据

已有数据库先执行：

```bash
npm run data:load:huawei
```

该命令会恢复`HUAWEI-TEST-*`固定测试计划及关联场景，不删除自行创建的业务数据。全新数据库首次启动会自动初始化，无需重复执行。

启动服务：

```bash
# 终端1
npm run dev:api:ts

# 终端2
npm run dev
```
